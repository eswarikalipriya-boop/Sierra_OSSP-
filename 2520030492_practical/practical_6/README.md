## Part 2 – Signal Handler

The `signal_handler.c` program demonstrates handling of three signals:

- `SIGINT` – generated by pressing Ctrl+C. The program displays a message and continues running.
- `SIGTERM` – terminates the process after displaying a message.
- `SIGUSR1` – displays a message and continues running.

### Compilation

```bash
gcc signal_handler.c -o signal_handler
